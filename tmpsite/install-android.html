Install Tunaroo on an Android TV box

About five minutes. You'll need the TV remote and, the first time, an internet connection on the box.

Why the extra steps? Tunaroo isn't in the Google Play Store yet, so Android asks you to allow the install once. That's normal for apps installed straight from a website.

Got an Amazon Fire TV Stick? It has its own steps: Install on a Fire TV Stick.

Way 1: with the Downloader app (easiest)

Downloader is a free app that fetches files from a web address, straight onto the box.

  1. Get Downloader

    On the box, open the Google Play Store (or Apps), search for Downloader by AFTVnews and install it. Skip this if it's already on the box.

  2. Type the Tunaroo address

    Open Downloader. In the address box, type tunaroo.com/tunaroo.apk and press Go. The file downloads in a few seconds.

  3. Allow the install

    When the file has downloaded, Downloader offers to install it. The first time, Android says it can't install apps from this source. Choose Settings, switch on Allow from this source for Downloader, then press Back.

    On some boxes this setting lives in Settings › Apps › Security & restrictions › Unknown sources, or Settings › Device Preferences › Security & restrictions.

  4. Install

    Choose Install, then Open (or Done to open it later from the apps row). Downloader may offer to delete the file afterwards. Say yes, it isn't needed any more.

Way 2: from a USB stick

Handy if the box has no Downloader app, or you'd rather set it up from a computer.

  1. Copy the file

    On a computer, download Tunaroo from tunaroo.com/download.html (the Android TV button) and copy the file tunaroo.apk onto a USB stick.

  2. Open it on the box

    Plug the stick into the box. Open a file manager app (many boxes have File Manager or Files; if yours doesn't, install File Commander or X-plore from the Play Store) and select the file.

  3. Allow and install

    Android asks you to allow installs from the file manager. Allow it, press Back, then choose Install.

First open

Tunaroo appears in your apps row with the orange roo icon. To keep it handy, hold OK on it and choose to move it to the front, or add it to your favourites row.

When it opens, it asks for your TV provider's details. The getting started guide takes you through that and making your first list.

Updating to a new version

Tunaroo checks for a newer version once a day and offers Update now. The first time, the box asks you to allow Tunaroo to install apps: switch on Allow from this source for Tunaroo, press Back and choose Update now again. Your provider details and lists are kept.

You can also update by doing the same steps again with the new file. Android asks whether to install the update over the top: say yes.

If it won't install

  • "App not installed": make sure the download finished (the file should be about 11 MB). Delete it, download it again and retry. If it still fails, check the box has some free storage.
  • "There was a problem parsing the package": the box is older than Android 7. Tunaroo needs Android 7 or newer.
  • No install button, or the setting keeps switching off: some boxes have a parental-control or "verify apps" setting that blocks installs. Look under Settings › Security.
  • The address won't load in Downloader: check the spelling, and that the box is online (try opening any other app that uses the internet).
