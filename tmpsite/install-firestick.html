Install Tunaroo on an Amazon Fire TV Stick

About five minutes. You'll need the Fire TV remote and an internet connection on the stick.

Why the extra steps? Tunaroo isn't in the Amazon Appstore, so the Fire TV asks you to allow the install once. That's normal for apps installed straight from a website.

1. Check your stick can run Tunaroo

Most Fire TV Sticks, the Fire TV Cube and TVs with Fire TV built in can run Tunaroo. Two newer models can't, because they don't run Android underneath and only install apps from the Amazon Appstore:

  • Fire TV Stick 4K Select (2025)
  • Fire TV Stick HD (2026)

To check, go to Settings › My Fire TV › About. If the software version starts with Fire OS, you're good. If it starts with 1. (Vega OS), Tunaroo won't install on that stick.

2. Turn on Developer options (once)

  1. Open About

    Go to Settings › My Fire TV › About.

  2. Press OK seven times

    With your stick's name highlighted at the top (for example Fire TV Stick 4K), press the OK (select) button seven times. A message says You are now a developer. If it says there's no need, Developer options are already on.

  3. Go back

    Press Back. Developer options now shows in the My Fire TV menu.

3. Install Tunaroo with the Downloader app

  1. Get Downloader

    From the Fire TV home screen, choose Find (the magnifying glass), search for Downloader, and install the orange app by AFTVnews. It's free.

  2. Allow Downloader to install apps

    Go to Settings › My Fire TV › Developer options › Install unknown apps and turn Downloader on.

    On older sticks this is a single setting called Apps from Unknown Sources. Turn it on.

  3. Type the Tunaroo address

    Open Downloader (allow it to use storage if it asks). In the address box, type tunaroo.com/firestick and press Go. The file downloads in a few seconds.

  4. Install

    Choose Install, then Open. Downloader may offer to delete the file afterwards. Say yes, it isn't needed any more.

4. Let Tunaroo update itself (once)

Tunaroo checks for a newer version once a day. When there is one, it offers Update now, downloads it and installs it over the top, keeping your login and lists. For that to work, the Fire TV has to allow Tunaroo itself to install apps:

  1. Turn Tunaroo on

    Go to Settings › My Fire TV › Developer options › Install unknown apps and turn Tunaroo on.

  2. Update when asked

    When Tunaroo says a new version is ready, choose Update now, then Install on the Fire TV's screen. It takes about a minute.

If Tunaroo forgets to ask, or you skipped this step, you can always update by opening Downloader and typing tunaroo.com/firestick again.

Using the Fire TV remote

  • Up and down look through what's on the other channels. Press OK to watch one.
  • Hold OK, or press the Menu button (three lines), to open the menu and Settings.
  • Fast-forward and rewind (⏩ ⏪) go to the next and previous channel, because most Fire TV remotes have no channel buttons.
  • The remote's volume buttons usually control the TV directly, so they may not show Tunaroo's own volume glow.

To find Tunaroo quickly, go to Apps (the three squares), highlight Tunaroo, press Menu and choose Move to front.

When it first opens, it asks for your TV provider's details. You can type them on your phone instead by scanning the QR code. The getting started guide takes you through it.

If it won't install

  • Downloader isn't in the store, or there's no Developer options: check you don't have a Fire TV Stick 4K Select or the 2026 Fire TV Stick HD (see step 1).
  • "App not installed": make sure the download finished (about 11 MB). Delete it, download it again and retry. Check the stick has free storage under Settings › My Fire TV › About › Storage.
  • "Install blocked" or no install button: Downloader isn't allowed to install apps yet. Repeat step 3.2.
  • Update now says to allow updates first: do step 4, then choose Update now again.
  • The address won't load: check the spelling and that the stick is online.
